# Amphibian Survey of South East Lois Hole Centennial Provincial Park

This repository includes the data file and R-code used to compile heat maps for the BLESS 2026 Amphibian Survey of Southeast Lois Hole Centennial Provincial Park(report included).

Acoustic data was condensed into one .csv file. 

"bchf" = Boreal Chorus Frog

"wf" = Wood Frog

"bt" = Boreal Toad

# Software Used:

Sonic Visualiser version 5.2.1

Rstudio version 2026.09.0 

R version 4.6.1
